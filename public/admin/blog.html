Blog desk

Review drafts, make small edits, then publish. No coding needed.

View public blog

This is the private blog desk for reviewing and publishing posts. Ask the site owner for the blog desk password if you do not have it yet.

Site owner setup (one time): put BLOG_ADMIN_PASSWORD=your-password in the project .env file, restart the server, then share that password with whoever reviews drafts.

Simple 3-step flow
  1. Open a draft under Needs review
  2. Read the preview. Change the title or text if something feels off
  3. Click Approve & publish — it goes live on the blog right away

Use Live on site later if you need to take a post down and turn it back into a draft.

Topic queue

Add ideas for the writing queue. Stay on niche: families supporting someone with addiction, homelessness/housing crisis, or mental health tied to those — not general wellness tips, and not eldercare. Each topic needs a title; the id is filled in automatically if you leave it blank. Use Generate to write an article with Gemini — it always opens a draft under Needs review. Used topics show Force generate instead. Saves (and generates) also back up topics.yaml to GitHub when configured, so the queue survives redeploys.

Download the queue to enrich topics offline (or with AI), then upload the full topics.yaml to replace it. Upload replaces the entire topic list and backs it up to git when configured.
